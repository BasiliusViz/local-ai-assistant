# Onboarding нового разработчика

## Первый день

Получить доступы: корпоративная почта, VPN, GitLab, Confluence, SigNoz.
Заявка оформляется через сервис-деск, категория «Доступы для нового сотрудника».
Срок выдачи — до двух рабочих дней.

Наставник назначается тимлидом в первый день. К нему идут все вопросы
первые две недели. Не стесняйтесь спрашивать: считается нормой задать
вопрос после 20 минут самостоятельных попыток.

## Локальное окружение

Минимальные требования: 16 GB RAM, Docker Desktop, Node.js 22 или выше,
Python 3.12, Go 1.23. Всё ставится через корпоративный репозиторий пакетов,
внешние источники заблокированы политикой безопасности.

Репозитории клонируются по SSH. Ключ добавляется в профиле GitLab.
HTTPS-доступ к репозиториям отключён.

После клонирования запустить make bootstrap — скрипт поднимет зависимости,
локальную базу в Docker и накатит фикстуры.

## Процесс разработки

Ветки от main, именование feature/JIRA-123-short-description.
Коммиты по Conventional Commits: feat, fix, chore, docs, refactor.
Merge request требует двух аппрувов, один из них — от владельца компонента.

Пайплайн должен быть зелёным. Красный пайплайн — не повод для аппрува,
даже если «падает не из-за меня». Сначала чиним, потом ревьюим.
