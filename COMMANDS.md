## Continue на вашем компьютере — руками

### 1

Закрыть VS Code полностью. Подтянуть репозиторий:

```powershell
git pull
```

### 2

Открыть из репозитория `continue-rules.v2.yaml` — в нём добавлен `jira_query`.
Скопировать всё от строки `rules:` до конца файла (там и `prompts:`).

### 3

Открыть `%USERPROFILE%\.continue\config.yaml`. Удалить в нём блоки `rules:` и
`prompts:` целиком и вставить на их место скопированное. Сохранить.

### 4

Открыть VS Code, Continue — новый чат, режим Agent. Написать (тема — любого
старого эпика):

```
jira: найди эпик про <тема>
```

Ждём: `jira_search`, эпик найден.

### 5

```
jira query: задачи этого эпика
```

Ждём: `jira_query` с `"Epic Link" = <номер>`, список задач.

### 6

```
jira: сколько сейчас открытых багов в <ваш проект>
```

Ждём: `jira_query` с `count_only`, число.
