# Команды

Задача: проверить живую Jira (`jira_query`) и эпики в Continue. 20.10.2026.
Одна команда — один шаг, строго по порядку. Не совпало с «Ждём» — прислать вывод.

Сделано на сервере: тип эпика `Epic`, `JIRA_LIVE=1`, контейнеры пересобраны,
эпики выгружены и проиндексированы, `--prune` их не трогает.

---

## На вашем компьютере (Windows, PowerShell)

В папке проекта, где лежит `setup-continue.ps1`. Сначала закрыть VS Code полностью.

### 1

```powershell
git pull
```

Ждём: `Fast-forward` или `Already up to date`.

### 2

Подставить свои адреса — те же, что при прошлой настройке.

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-continue.ps1 -OllamaUrl http://АДРЕС-OLLAMA:11434 -ServerUrl http://АДРЕС-СЕРВЕРА -Model qwen3.6:35b -ContextLength 32768 -SkipExtension
```

Ждём: везде `[OK]`.

### 3

Открыть VS Code, в Continue — новый чат. Написать (тема — любого старого
эпика, который давно никто не трогал):

```
jira: найди эпик про <тема>
```

Ждём: модель зовёт `jira_search` и находит этот эпик.

### 4

```
jira query: задачи этого эпика
```

Ждём: модель зовёт `jira_query` с `"Epic Link" = <номер эпика>`, приходит список задач.

### 5

```
jira: сколько сейчас открытых багов в <ваш проект>
```

Ждём: `jira_query` с `count_only`, в ответе число.
